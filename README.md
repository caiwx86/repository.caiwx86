# Repository caiwx86

## 仓库安装方式 1
1. Kodi-设置-插件-从 zip 安装，找到并安装repository.caiwx86-xxx.zip或repository.caiwx86.ghproxy-xxx.zip  

## 仓库安装方式 2
从 Release 下载插件仓库 zip 文件安装

## 仓库说明
- **repository.caiwx86**: 库中插件直接从 GitHub 原始链接下载
- **repository.caiwx86.ghproxy**: 库中插件从 gh-proxy.com 转发下载 (GitHub 访问不稳定的地区可以用这个)

## 插件安装
安装完仓库插件后，选择：
Kodi-设置-插件-从库安装-Kodi caiwx86 Addon Repository，即可浏览并安装所需插件。

## 注意事项

 - Kodi 的插件仓库并不是实时更新的 (可能是 24 小时更新一次)，如果需要安装最新插件，你可能需要在仓库页手动触发更新仓库。
